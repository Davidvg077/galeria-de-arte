# Sitio HTML archivado

Este directorio conserva la versión HTML anterior, que ya no es la aplicación
principal. Las páginas y sus recursos estáticos están en `site/`; el servidor
Express anterior está en `server.js`. La aplicación vigente se inicia desde
`back/api-gateway/server.js` y su interfaz Astro vive en `front/src/`.

Los manifiestos y entrypoints que usan Docker, Render y los comandos del
proyecto permanecen en sus ubicaciones compatibles.
